# Treasury — HFV Protocol  

📅 Updated: 26 August 2025  

## Allocation
- **18% of supply** = 12,600,000 HFV  

---

## Split
- **Treasury Reserve** → funds staking rewards, ecosystem projects, audits.  
- **Team/Devs** → locked via vesting (DAO decides parameters).  

---

## Vesting (Team/Devs)
- **TGE %**: configurable by DAO  
- **Cliff**: default 6 months  
- **Linear vesting**: 24 months  

---

## Treasury Planner
- DAO submits project funding proposals.  
- Recorded in planner table (project, category, amount, months, status).  
- Exportable to CSV for DAO review + transparency.  

---

## Governance
- DAO controls both Treasury Reserve and Team/Devs allocation.  
- Only vested/unlocked tokens can be moved.  
- All treasury actions require DAO approval.
