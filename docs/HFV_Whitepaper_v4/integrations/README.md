# Integrations — HFV Protocol  

📅 Updated: 26 August 2025  

## Purpose
HFV grows by integrating with wallets, exchanges, infra providers, and community platforms.

---

## Current Integrations
- **Wallets**: MetaMask, WalletConnect (Reown protocol)  
- **Exchanges**: Uniswap (ETH/HFV, USDC/HFV pairs)  
- **Infra**: Alchemy (RPC), Etherscan (verification), Dune dashboards  
- **Community**: Discord, Telegram, X (Twitter)  

---

## Future Integrations
- **Centralized exchange listings** (CEX)  
- **Real-time telemetry dashboards** for treasury & staking  
- **DAO proposal explorer** integrated into main DApp  
- **Grant programs** with ecosystem projects
